# BI-Tableau
This project contains an interactive Tableau dashboard analyzing Superstore sales performance across different regions.  

## 📊 Insights:  
- Best Performing Region: **West** 
- The most profit: **The Copiers**
- The highest profit: **California**
- **Upward trend** in months
- Data processed using **Excel & Tableau**  

## 📁 Files:  
- `SuperstoreDashboard.twb` → Tableau workbook  
- `Sample - Superstore_Data.xlsx` → Raw dataset
